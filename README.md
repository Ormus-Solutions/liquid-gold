# liquid-gold

> Five pours. One crucible. Ormus open-source kits for TypeSafe-style Jev patterns — confidence, judgment, assay, cascade, and filter.

Public index for the **Liquid Gold** suite under [Ormus-Solutions](https://github.com/Ormus-Solutions). Each package is MIT, TypeScript, Vitest-mocked (no live API required).

Themes draw from public **TypeSafe** & **Vercel** Jev guides and the free **master-Jev** (Daniel Ch) teaching lane — paraphrased into Ormus-shaped tools, not copies.

## The five

| Repo | One-liner |
|------|-----------|
| [aurum-gate](https://github.com/Ormus-Solutions/aurum-gate) | Confidence-gated Jev action router (Pattern 2). |
| [quicksilver-judge](https://github.com/Ormus-Solutions/quicksilver-judge) | Staged PR pre-filter — Raven Judge shape. |
| [gold-assay](https://github.com/Ormus-Solutions/gold-assay) | Vibium UI proof scorer before claiming GREEN. |
| [molten-cascade](https://github.com/Ormus-Solutions/molten-cascade) | Jev → code → LLM cascade (Pattern 4). |
| [karat-filter](https://github.com/Ormus-Solutions/karat-filter) | Retrieve-then-judge + speculative fan-out (Pattern 5). |
